# GitHub Publish Checklist

Use this after creating the GitHub repository.

## Before first push

- Confirm the repository name is `mcp-redteam`.
- Replace repository URLs if you publish under a different owner than
  `codezxsWIN`.
- Review generated reports before committing; they can contain transcripts or
  local paths.
- Keep `dashboard-desktop.png` and `dashboard-preview.png` at the **repository
  root** (not under `mcp_redteam/`) because the README and LinkedIn draft use
  them as preview images.
- Regenerate screenshots after UI changes:
  `python scripts/capture_dashboard_screenshots.py` (requires `playwright`).
- Keep `dist/` out of git; it is generated by `uv build`.

## Commands

```pwsh
git init
git add .
git commit -m "Prepare mcp-redteam for public launch"
git branch -M main
git remote add origin https://github.com/codezxsWIN/mcp-redteam.git
git push -u origin main
```

## Verify after push

- GitHub renders the README screenshot.
- The CI workflow passes.
- The license is detected as MIT.
- Issue templates appear under New issue.
- The LinkedIn post in `docs/linkedin-post.md` has the final repository URL.
