# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-05-29

- Initial public-ready release candidate.
- Added runtime probes for tool poisoning, output injection, rug-pull behavior,
  and resource exfiltration risk.
- Added stdio and streamable HTTP target support.
- Added terminal, JSON, Markdown, and standalone HTML reports.
- Added local Starlette dashboard for interactive scans.
- Added intentionally vulnerable MCP server fixture and end-to-end tests.
